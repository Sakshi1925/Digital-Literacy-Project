Project Overview

This repository is my submission for the CSE0001 Digital Literacy project at VIT Bhopal University. In this project, I take on the role of a Student Digital Ambassador — helping peers navigate the digital world through five hands-on tasks covering digital tools, professional online presence, coding platforms, email communication, and cybercrime awareness.This project focuses on improving digital literacy skills by completing various tasks such as searching for information online, using reliable websites, and organizing data in a structured format. It also includes learning how to manage files, upload content to GitHub, and properly document work using screenshots and explanations.
